# Evaluating Sources (Sample)

**Source:** Training sample. **Published:** 2024-04-10.

## Credibility checklist

| Signal | Stronger | Weaker |
|--------|----------|--------|
| Author | Named expert, affiliation | Anonymous |
| Evidence | Data, methods, citations | Opinion only |
| Publisher | Government, university, journal | Unknown blog |
| Date | Recent for fast-moving topics | Undated |

## Red flags

- Sensational claims without data
- No references for factual statements
- Conflicts of interest not disclosed

## Agent behavior

If sources conflict, report both views and state which has stronger evidence. If none apply, say **insufficient evidence**.
